# Handoffs

This directory contains dated handoff and validation-evidence documents. They preserve operational history, decisions, measured results, artifact provenance, and the state observed at a specific time.

A handoff is not a standalone normative contract. For current implementation behavior use merged code and tests; for V-I logger standards and architecture use [`../vi-logger/`](../vi-logger/README.md); for open or future work use the relevant GitHub Issue. Physical validation claims may cite a handoff or the focused validation report, but must not be inferred from design intent.
